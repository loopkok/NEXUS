# 2026-09-30 Web 桌面应用风格重设计

## 视觉与交互

- 根据用户提供的深色 macOS 风格参考图重做窗口、侧栏和卡片层级。
- 增加外部背景、圆角窗口、柔和阴影、内侧高光，以及紫灰和青绿渐变。
- 顶部机器人概览增加组件示意、连接数、关节维度与视觉通道。
- 组件示意按配置中的机械臂与末端数量生成，明确标注为非运动学视图，不作为实际姿态或碰撞判断依据。
- 组件卡片展示实际反馈频率和最近 40 个采样点；缺流不生成虚构遥测。
- 压缩机器人选择卡片，运行时默认折叠完整配置，显示冻结配置和功能摘要。
- 数采页增加录制状态、数据段和时长卡片；训练页增加流程分区和作业空状态；推理页突出模型与控制权。
- 保留统一 API、驱动控制顺序、配置锁定、录制退出保护和原有操作确认。

## 验证范围

TypeScript/Vite 构建和隔离假驱动浏览器验证。未执行物理驱动、真实运动、归位或 GPU 训练；未重启用户真机 Web。
