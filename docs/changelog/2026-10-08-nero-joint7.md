# 2026-10-08：定位 Nero 第七关节归位残差，增加停机前诊断

- 根据第二次真机日志，前六轴误差很小，第七轴误差为左 4.5452°、右 4.1662°，均超出原 0.05 rad 到位阈值。没有将整体目测到位直接视为七轴均已到位。
- 归位每两秒打印逐轴误差、控制器状态与七轴驱动状态；归位失败时先保存故障前快照，再执行停止，避免用停机后的状态推断故障原因。
- 增加只读 `drivers/<component>/diagnostics` 服务，读取 SDK 现有缓存并返回最近一次停机前诊断。读取路径不发送任何硬件指令。
- 新增 J7 残差与诊断无副作用的 ROS 检查，以及使用实际 SDK 与内存传输的完整七轴发包检查；11 项 Nero 检查通过。
- 真机仅被动监听 CAN 并查询固件版本，确认两臂均为 1.10，保留 DEFAULT 适配器。实际 J7 偏差原因与 XHand 参数错误仍待现场记录确认，未宣布真机归位已修好。
