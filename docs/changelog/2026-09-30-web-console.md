# 2026-09-30 Web 控制台统一

## 界面

- 删除独立 NEXUS 页面，系统页作为机器人配置与启动入口。
- 统一导航：系统、遥操、数采、数据与训练、推理、日志与诊断。
- 使用“机器人配置”“机器人系统”“驱动”“自由度”等术语。
- 根据 profile 与驱动注册表展示组件、自由度、反馈和归位能力。
- 驱动适配器新增 `supports_viewer` 能力，仿真窗口不按机器人名称判断。
- 保留折叠的旧版预设入口；运行统一机器人接口时隐藏旧硬件操作。
- 跨页面保留设置，刷新后恢复服务端运行配置；真机初次选择默认假驱动调试，数采和推理默认关闭。

## 视觉重设计

- 固定侧边导航，机器人概览、配置和驱动操作分区。
- 机器人选择使用卡片，运行模式使用分段按钮，功能选项使用开关卡片。
- 统一深色中性色、薄荷绿主操作、字体层级、间距与控件尺寸。
- 顶部隐藏待机时无效的旧遥操按钮，待机反馈使用中性颜色。
- 高级模型参数默认折叠，增加窄屏布局和键盘焦点样式。

## 控制

- 驱动检查、使能、归位及急停通过同一接口提交异步操作，显示执行中、成功或失败。
- 归位等待上限 120 秒，防止原 4 秒 HTTP 等待被误认为运动失败。
- 拦截重复普通驱动操作；急停仍可提交。
- 暂停使用当前实例的 `teleop_disarm`，恢复使用重锚；不依赖策略节点。
- 旧硬件 API 在统一机器人运行时路由到当前驱动，或拒绝不支持的模式，避免误操作 Astral。
- 录制、暂停录制或保存期间拒绝退出机器人系统；驱动操作执行期间也拒绝直接退出。
- 急停文案明确区分软件命令封锁与硬件失能。

## 数据与诊断

- 数采页提供任务、录制、保存、暂停/继续、语义相机预览和原始质量状态。
- 数据与训练页提供同步、对齐质检、导出、训练、日志、产物、取消及同布局重新提交。
- 推理页提供模型清单与服务配置、策略控制和人在环接管。
- 监控统一输入、候选命令、最终命令及反馈的频率与接收年龄。
- 显示最终命令发布者数量和发布 QoS、关节跟随误差；接收年龄不标称为端到端延迟。
- 运行记录冻结配置、Git 提交、布局哈希及操作事件；支持下载包含诊断、作业和日志的 JSON 测试报告。
