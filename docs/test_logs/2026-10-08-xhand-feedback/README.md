# XHand 反馈稳定性测试记录

日期：2026-10-08。主机：192.168.0.231，ROS 2 Humble。

## 定位结果

原生手驱动持续输出约 100 Hz，NEXUS 桥接发生回调饥饿。Web 根据 0.5 秒反馈时效显示在线状态，数秒的桥接断流因此触发反复离线与启动按钮禁用。原生驱动日志同时确认桥接命令发布的 best effort 与厂商可靠订阅不兼容。

基线代码为 `45c91d8`；修复代码为 `5629a5e`。两次测试均在独立 ROS 域 184 进行，仅运行两只手的状态读取和默认未使能的桥接，额外输入约 67–72 Hz 候选流，不启动机械臂或仲裁节点。基线 45 秒，修复版 60 秒。

| 反馈链路 | 基线频率 | 基线最长间隔 | 修复后频率 | 修复后最长间隔 |
|---|---:|---:|---:|---:|
| 左手原生反馈 | 100.00 Hz | 12.8 ms | 100.00 Hz | 12.1 ms |
| 右手原生反馈 | 100.00 Hz | 20.4 ms | 100.00 Hz | 15.0 ms |
| 左手 NEXUS 反馈 | 9.02 Hz | 3069.6 ms | 100.02 Hz | 13.3 ms |
| 右手 NEXUS 反馈 | 1.02 Hz | 7928.6 ms | 100.03 Hz | 12.0 ms |

基线左右手分别出现 19、16 次超过 0.5 秒的反馈间隔；修复后均为 0。修复版未观察到原生手部运动命令，SDK 读取错误和桥接反馈拒绝计数均为 0。

## 验证项目

- 主机编译 `nexus_core` 与 `xhand_control_ros2`。
- ROS 集成测试：合成反馈约 100 Hz 与候选流压力下保持 ready，Web 使用的 MonitorNode 持续判定在线；反馈过期后 Web 判定离线且禁止输出命令。
- ROS 集成测试：重排实测关节名正确恢复固定顺序；显式使能前无原生命令，合成使能后能与厂商可靠订阅匹配。
- ROS 集成测试：过期/未来/零时间戳、维度错误、重复关节名、NaN、超限和多设备消息被拒绝；后续合法反馈恢复 ready。
- C++ 测试：SDK 串口/忙/CRC 错误，以及全部 12 个关节的 NaN/Inf 均不作为有效反馈；合法数据恢复通过。
- 保留原有 profile、数据布局、仲裁与控制频率的契约回归测试。

正式目录构建 2 个包成功；19 个契约测试、3 个 ROS/Web 集成测试和 1 个 C++ 测试全部通过。ROS 压力测试记录 286 帧有效反馈、209 帧候选目标，最大反馈间隔 11.6 ms。`tests_20261008.log` 中的过期时间戳 ERROR 是测试主动注入的预期拒绝日志。

### 最终退出验证

60 秒对比结束时，右桥接在 SIGINT 关闭 ROS 上下文后记录了一次消息转换异常，原始记录保留在 `fixed/right_ee_bridge.log`。随后在 `37e809c` 中增加仅针对无效上下文的退出处理，运行中的异常仍会报错。

正式目录再次完成 5 个 ROS/Web/退出测试，其中新增 2 个测试分别验证退出异常处理与运行错误不被隐藏。连同原有 19 个契约测试与 C++ 测试，共 25 项通过。另运行 15 秒双手只读压力测试，四路原生/NEXUS 反馈均约 100 Hz，没有超过 0.5 秒的断流，没有运动命令，没有 QoS 不兼容警告或退出异常。详见 `final/` 和 `final_tests_20261008.log`。测试结束后确认手部驱动全部停止、串口无人占用；旧的隔离 Web 预览进程也已停止。

合成命令测试在 ROS 域 185 运行，使用临时机器人实例与重映射后的测试原生话题，没有启动硬件驱动。只读实物测试没有执行使能、归位、手指运动或完整真机遥操；未进行 USB 插拔、断电测试。SDK 被动读取接口没有逐帧硬件时间戳，本次结果验证 ROS 反馈链路与 SDK 返回状态，不能据此宣称已验证所有硬件掉线情形。

## 复现只读反馈测试

确保原有手部驱动停止、串口无人占用，然后在主机执行：

```bash
cd /home/loopkok/NEXUS
source /opt/ros/humble/setup.bash
source install/setup.bash
export ROS_DOMAIN_ID=184 ROS_LOCALHOST_ONLY=1
python3 scripts/nexus_xhand_feedback_probe.py \
  --profile src/nexus_core/profiles/nero_dual_xhand.json \
  --start-readers --stress-candidates --seconds 60 \
  --output /tmp/nexus_xhand_feedback_check
```

脚本只临时启动手部状态读取和未使能桥接，检测到串口被占用会拒绝启动；结束后停止自己启动的进程。报告输出各流频率、最大间隔、超时次数及原生命令观察数量。

原始记录存放在本目录的 `baseline/`、`fixed/` 及构建/测试日志中。
