## 目前能与不能得出的结论

- 归位未通过是实测 J7 未到位，不是网页文字误报。当前 0.05 rad 规则正确拒绝了这次归位。

- J7 保持原位置、指令锁存/控制模式问题、负载/机械阻挡或关节驱动问题，仍需区分。没有证据支持直接改帧顺序、重发目标、切 JS 追赶、修改电流/增益或放宽容差。
